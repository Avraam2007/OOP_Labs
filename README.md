# <span style="color:#606ac4">Welcome to <span style="color:green">ECommerce</span></span>

To use this app you should unzip this archive: **OOP_Main/Build_app.zip**. It has `.exe` file and crucial libraries.

## Project structure:
 + **`criteria`** - Lab tasks
 + **`Lab6Benchmark`** - benchmark test from Lab #6 (`concat with +` vs `StringBuilder`)
 + **`Lab8Benchmark`** - benchmark test from Lab #8 (`List<T>` vs `LinkedList<T>`)
 + **`OOP_Main`** - main project code
    + **`ClassDiagram1`** - UML-scheme of the project
    + **`Build_app`** - ready-to-use app
        + **`DataStorage`** - saved order receipts and JSON files with saved products, suppliers, orders and users.
            + **`bin`** - saved products in binary files
            + **`text`** - saved products and users in CSV-like format
        + **`Backups`** - last 5 backup archives
        + **`Logs`** - app logs to check its work
